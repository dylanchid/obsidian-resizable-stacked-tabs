# Resizable Stacked Tabs

Drag a stacked tab's right edge to set its width without leaving stacked-tab mode.

## Install manually

Copy `manifest.json`, `main.js`, and `styles.css` (if present) into `<vault>/.obsidian/plugins/resizable-stacked-tabs/`, then enable the plugin in Obsidian.

## Develop

Run `npm install` and `npm run build` from this directory.
